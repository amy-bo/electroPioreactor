electroPioreactor OS

A Raspberry Pi image based on the official Pioreactor OS with the electroPioreactor plugin pre-installed and configured.

Flash with Raspberry Pi Imager

  1. Open Raspberry Pi Imager.
  2. Click Choose OS → scroll to the bottom → Use custom.
  3. Paste the custom URL below and press Enter:

https://amy-bo.github.io/electroPioreactor/os-list.json

Note: The latest image is always linked from the Releases page. The JSON above is automatically updated when a new release is published.

Hardware connections

  • Electrode pair → LED channel D
  • CO₂ solenoid → PWM channel 4
