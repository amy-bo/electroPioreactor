# HOB Enrichment Methodology – Irvine River

A protocol for enriching hydrogen-oxidising bacteria (HOB) from the Irvine River using the [AEP0.1.1](https://github.com/amy-bo/electroPioreactor) electroPioreactor, with MC02 medium provided by Bingqiao of Edinburgh University's Chris French Lab. Adapted for this sampling site and pre-made medium.
