# Mixed-Culture electroPioreactor (MEP)

The MEP was the only electroPioreactor until we started work on the Aseptic electroPioreactor (AEP) for use with single strains. We are now resuming work on the MEP as a lower-cost version for mixed-culture use, initially producing two units for the 2026 MSc Industrial Projects of the [School of Biological Sciences](https://biology.ed.ac.uk/) at the University of Edinburgh.

For the wider electroPioreactor project see [electropioreactor.org](https://electropioreactor.org).
